# Editable GitHub profile

## Install
1. Extract the ZIP and copy everything inside the folder into the root of your AshuNewatia/AshuNewatia repository (include the hidden .github folder). Do not upload the ZIP itself.
2. Delete these files from the repository, they are no longer used: assets/circuit.svg, assets/identity-circuit.svg, assets/project-circuit.svg, assets/outbound-circuit.svg, assets/waneella.gif.
3. Commit. The workflow runs on push and hourly, refreshing the telemetry block, assets/analytics.svg, assets/language-signal.svg and assets/telemetry.json.

## What is in the SVGs now
- Fetched from GitHub (regenerated by the workflow): analytics.svg, language-signal.svg
- Header only: hero.svg (name and typing roles, drawn in a robotic font). It is the one non-data SVG, kept because it is the header.

## Where to edit
| Content | Where |
| --- | --- |
| Subtitle, intro, links, stack, projects, footer | README.md |
| Header name, typed roles, HUD text | top of scripts/generate_art.py, then run `python scripts/generate_art.py` and upload assets/hero.svg |
| Avatar | replace assets/avatar.gif (shown at 150px) |
| Telemetry block | automatic, do not edit between the START/END markers |
